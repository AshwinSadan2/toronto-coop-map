## What we learned
- Claude's chat Notion connector and the project's connection are in different workspaces (Northern Loop vs Ashwin's Notion). A page made through chat is invisible to the script.
- Notion search returns database rows too, so the script must read every page of results to find the home page (fixed).
- Google's field set with hours and phone is the pricier tier: 1,000 free per month, then $35 per 1,000. The cache in `data/cache/google/` and a 400-call cap keep it at $0.
- CARTO map tiles need a key now; using OpenStreetMap tiles with a muted filter instead.
